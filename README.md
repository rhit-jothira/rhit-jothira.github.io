# Modern Portfolio

A modern, interactive portfolio for showcasing projects and seeking internship opportunities.

## Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React

## Run Locally

**Prerequisites:** Node.js (v18 or higher recommended)

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. Open `http://localhost:3000` in your browser.

## Deployment

This project is configured to be deployed to GitHub Pages using GitHub Actions.

1. Push your code to your GitHub repository.
2. Ensure you have GitHub Pages enabled in your repository settings (Settings -> Pages -> Build and deployment -> Source: GitHub Actions).
3. The included `.github/workflows/deploy.yml` will automatically build and deploy your site whenever you push to the `main` or `master` branch.
